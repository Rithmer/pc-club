# CTRL

CTRL — приложение компьютерного клуба для выбора места, бронирования и управления игровыми сессиями. Гости видят зал и тарифы, игроки оформляют и отслеживают брони, администраторы управляют работой клуба.

## Запуск

Нужны Docker и Docker Compose. Склонируйте фронтенд и бэкенд в одну папку. Названия каталогов `pc-club` и `CyberClub` должны совпадать с примером:

```text
workspace/
├── pc-club/
└── CyberClub/
```

В папке `pc-club` создайте `.env` из примера:

```sh
cp .env.example .env
```

Замените `CYBERCLUB_JWT_KEY` на собственный секрет длиной от 32 байт. Затем запустите приложение:

```sh
docker compose up --build -d
```

Откройте [http://localhost:8080](http://localhost:8080). Для остановки выполните `docker compose down`. Данные SQLite сохраняются в Docker volume `club_data` между перезапусками.

## Локальная разработка

Нужны Node.js 22.12+, pnpm 10.30.1 и .NET SDK 8. Запустите бэкенд по [его инструкции](../CyberClub/README.md), затем в `pc-club/` выполните:

```sh
pnpm install
pnpm dev
```

Сайт откроется на [http://127.0.0.1:5173](http://127.0.0.1:5173). Если бэкенд запущен не на порту 5000, задайте его адрес через `API_PROXY_TARGET` в `.env`.

## Тестовый доступ

| Роль | Почта | Код |
| --- | --- | --- |
| Игрок | `player@example.com` | `1234` |
| Администратор | `admin@example.com` | `1234` |

В текущей конфигурации вход использует фиксированный код, а онлайн-оплата имитируется без списания денег. Эти механизмы предназначены для знакомства с приложением; для реальных платежей и подтверждения личности нужны рабочие интеграции.
